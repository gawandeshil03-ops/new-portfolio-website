# Shil Gawande — Data Analyst Portfolio

A lightweight, GitHub-ready static portfolio website showcasing three analytics projects built around **SQL for data preparation** and **Tableau for analysis, dashboards, and business storytelling**.

## Featured projects

- **Ecommerce Sales Intelligence Analytics** — sales, product, customer and KPI analysis
- **Supply Chain Decision Intelligence Platform** — supply-chain performance and operational decision support
- **Subscription Product Analytics** — funnel, conversion, churn, cohort retention and revenue-related analysis

## Sections

- Hero / introduction
- Selected projects
- Technical skills
- Education & profile
- Contact / resume

## Run locally

No build step is required. Open `index.html` directly in a browser, or serve the folder with any static web server.

Example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy to GitHub Pages

1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In **Settings → Pages**, select the main branch and root folder.
4. Save and open the generated Pages URL.
